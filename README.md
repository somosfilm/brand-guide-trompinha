# Brand Guide Trompinha

Guia visual de identidade da marca **Trompinha**.

🌐 **Acesse online:** https://somosfilm.github.io/brand-guide-trompinha/

## Conteúdo

Documento HTML único (`index.html`) com a identidade visual completa: logo, cores, tipografia, aplicações e diretrizes de uso.

## Como visualizar localmente

```bash
git clone git@github.com:somosfilm/brand-guide-trompinha.git
cd brand-guide-trompinha
open index.html  # abre direto no browser padrão
```

## Atualizando o guia

Substitua o `index.html` por uma versão nova e faça commit:

```bash
git add index.html
git commit -m "update: brand guide v5"
git push
```

O GitHub Pages atualiza automaticamente em ~1-2 minutos.
